## How to Use

1. Read each lesson — the "Plain English" and "Real-world analogy" sections explain the _why_
2. Try the practice exercise **before** looking at the solution
3. Compare your solution with the provided one — different approaches are fine!
4. Do the "Your turn" challenge at the bottom of each lesson

## Format

Each lesson follows the same structure:
- **What is X?** — plain English explanation
- **Real-world analogy** — makes it click
- **Code examples** — with explanations
- **Practice exercise** — build something real
- **Solution** — try it yourself first!
- **Quick recap** — key takeaways
- **What's next?** — navigation

Happy coding! 💛
